# Jenkins First Public Repository

This repository is created for Jenkins practice to create build jobs and run builds in Jenkins.

## Purpose
- Learn Jenkins CI/CD pipeline configuration
- Practice creating and running build jobs
- Explore Jenkins automation capabilities

## Contents
- **Jenkinsfile** - Pipeline definition for Jenkins
- **build.sh** - Build script for compilation
- **test.sh** - Test execution script
- **hello.py** - Sample Python application

## How to Use
1. Create a new Jenkins job pointing to this repository
2. Configure the job to use the Jenkinsfile for pipeline definition
3. Trigger builds and monitor the pipeline execution

## Learning Resources
This repo helps practice:
- Pipeline as Code (Jenkinsfile)
- Automated builds and tests
- Build job configuration
- Jenkins integration with GitHub
